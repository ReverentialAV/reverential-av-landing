What Measured Commissioning Actually Changes — and What It Proves

Most churches replace their sound system two or three times before anyone measures the room. Each replacement inherits exactly the same problem as the equipment it replaced. Here is why that cycle keeps repeating, and how to break it.

Thomas Jeffrin Founder, Reverential AV Integration 25 October 2026 7 min read

Every loudspeaker that comes out of a manufacturer's box has been built to a specification measured in an anechoic chamber: a room designed to have no reflections, no background noise, and no acoustic character. The room where your system will actually operate is nothing like that.

By the time a loudspeaker is mounted at 5 metres height in a stone church and driven by a DSP with factory default settings, its real-world behaviour will differ from the specification sheet in ways that matter. The room adds its own frequency response. Boundary effects change the low-end behaviour. Adjacent loudspeakers interact through comb filtering. Commissioning is the process of measuring these differences and correcting for them.

What commissioning actually involves

A proper commissioning process involves several stages. First, a transfer function measurement — playing a reference signal through each loudspeaker and measuring what arrives at multiple points in the room. This reveals the system's actual frequency response in the room, any phase anomalies, and the time alignment between loudspeakers.

Second, time alignment. In any system with more than one loudspeaker cluster, the signals must arrive at the listening position within a few milliseconds of each other. A delay speaker that is not time-aligned creates a doubling effect — the listener hears two distinct sources rather than one coherent one.

Third, equalisation. The system is EQ'd to produce a flat frequency response at the listening position, correcting for the room's acoustic contribution to the signal. Fourth, gain structure — the sensitivity of every element in the signal chain is set so the mixing position operates in a sensible, controllable range.

A system that has not been measured after installation has not been commissioned. It has been installed. Those are different outcomes.

What the data shows

Before commissioning, a typical installed system in a medium-sized church will show a frequency response at the back row that varies by 20–30 dB across the audible spectrum. Some frequencies are over-represented (usually bass-mid around 200–400 Hz). Some are absent (often the upper midrange critical for consonant intelligibility at 2–4 kHz).

After commissioning, the same system at the same seat will show a response within ±6 dB across the speech-critical frequency range. Speech intelligibility improves not because new equipment was added but because the existing equipment is now performing in the room rather than against it.

What the commissioning report proves

A commissioning report records, with measurement data, what the system achieves on the day it is handed over: the transfer function, time alignment data, gain structure settings, DSP snapshot — all documented. When the system sounds different in twelve months, that baseline tells you whether something has changed or whether the room has changed. Without a baseline, you are diagnosing in the dark.

What to ask before signing off on any installation

"Can you provide the commissioning report — the Smaart transfer function data taken after alignment, with the DSP snapshot and signal chain documentation?" If the contractor cannot produce this, the system has not been commissioned.

On the difference commissioning makes to the operator

The most underestimated outcome of proper commissioning is operational reliability. A system that is aligned, documented, and handed over with a training session is a system that a volunteer operator can run confidently from week one. The gain structure is set so small fader movements produce small level changes. The EQ is set so the room sounds right at unity — the operator is mixing music, not fighting the room.

The systems I see that are hardest to operate are not poorly specified. They are well-specified systems that were never properly commissioned. The equipment is capable. Nobody ever set it up to behave that way.
