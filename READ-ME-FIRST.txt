BLOG WORKFLOW — adding a new post:
-----------------------------------
1. Copy blog/blog-post-template.html
2. Rename: blog/your-post-title-here.html
3. Fill in the 8 marked fields at the top (title, date, URL etc.)
4. Write the article body
5. Add a card to blog/index.html (copy the existing card block)
6. Add one line to sitemap.xml
7. Upload blog/your-post-title-here.html and blog/index.html to GitHub
8. Cloudflare deploys in 60 seconds — live

WHY TWO FILES ARE NAMED index.html:
-------------------------------------
  /index.html       serves reverentialav.in/         (main website)
  /blog/index.html  serves reverentialav.in/blog/    (blog listing)
These are DIFFERENT files in DIFFERENT folders. GitHub and Cloudflare
treat them as separate pages. The naming is correct web convention.
