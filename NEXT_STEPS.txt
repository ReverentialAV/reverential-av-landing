IF THE PAGE WILL NOT LOAD
-------------------------

   Console says "Script error." with no file or line:
   that is a cross origin script message. The page script is inline, so
   the usual cause is Cloudflare Rocket Loader.

       Cloudflare -> your domain -> Speed -> Optimization
       -> Content Optimization -> turn Rocket Loader OFF

   Both script tags already carry data-cfasync="false" to opt out, but
   turning it off is the reliable fix. Brave Shields and other blockers
   cause the same symptom, so test with those disabled too.

   If the app fails to mount it now prints the real error on screen with
   your phone and email, instead of going blank. Screenshot that.
